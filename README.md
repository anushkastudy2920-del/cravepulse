# cravepulse
**Food Delivery & Cloud Kitchen Management System | Full-Stack Web Development**

Developed a responsive food delivery web application with three integrated modules for customers, kitchen staff and delivery management. Built an interactive 2D dish customizer with live price and nutrition updates, a kitchen dashboard for managing orders and inventory, and a delivery tracking system that uses Dijkstra's algorithm to calculate the shortest routes based on traffic conditions. Also implemented features like group bill splitting, UPI payment links, order status tracking and rider communication. Built the application using vanilla web technologies without relying on external npm packages or heavy frameworks.

**Technologies Used:** HTML5, CSS3, JavaScript (ES6+), Dijkstra's Algorithm, HTML5 Canvas, Web Audio API.
